# Yi Li's personal homepage

A static personal homepage for CSI205TC Question 2, following Lab Week 6's native HTML/CSS/JavaScript approach.

## Files

- `index.html`: page content and navigation.
- `css/style.css`: layout, colours and responsive styles.
- `js/main.js`: mobile menu controls.
- `assets/CV.pdf`: English CV based on the existing Yi_Li_CV.docx.
- `assets/monogram.svg`: original initials graphic, used in place of a portrait.
- `assets/favicon.svg`: original browser icon.

## Preview and deployment

Open `index.html` in a browser. No build or package installation is required.

Upload the contents of this folder to the root of `nut256/nut256.github.io`, preserving the `css`, `js` and `assets` folders. In Settings > Pages, select Deploy from a branch, branch `main`, folder `/ (root)`, then save. After deployment, verify `https://nut256.github.io/` while signed out.
